A pure Python program that draws Thursday 19 November 2026 as a vertical "day in hours" timeline: six verified stories from that day, from GTA VI going live at 05:00 UTC to Cyclone Akvan turning very severe at 18:00 UTC, each with a UTC time badge, a headline and a one-line summary on a timeline spine, under a header naming the day and a footer summing it up in one sentence. It uses only the standard library, draws every pixel itself with a small built-in bitmap font and PNG encoder, and writes the same bytes on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
